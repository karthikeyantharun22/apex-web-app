# APEX — Personal Advancement Operating System

> **Evidence-Based Advancement Engine across Physical Capability, Style, Communication, Wealth, and Mastery.**

Built locally with Next.js (App Router), Tailwind CSS, Three.js 3D WebGL Life Sphere, Lucide Icons, and Local-First Encryption Enclave.

---

## 🚀 Key Modules & Capabilities

1. **Life Telemetry & 3D Life Sphere**:
   - High-performance interactive Three.js 3D Life Sphere visualizing domain balance.
   - Comprehensive telemetry tracking (sleep architecture, workout volume, liquid runway, active recall retention).
   - Daily Evidence-Based Execution Protocol.

2. **Body & Physique Coach**:
   - NSCA / ACSM progressive overload and hypertrophy volume landmarks (MEV -> MRV).
   - 1RM Brzycki calculator and workout logger.
   - Automatic Pushback Guardrail flagging dangerous caloric deficits (>28%) and rapid weight drops.

3. **Style & Image Architecture**:
   - High-contrast capsule wardrobe manager with cost-per-wear tracking.
   - Seasonal color matrix (Deep Autumn / Cool Olive) and event-based outfit generator.

4. **Communication & Negotiation**:
   - Draft tone analyzer flagging needy and defensive markers.
   - Executive density rewrite generator (Munter / Voss models).
   - High-stakes conversation roleplay sparring simulator with real-time feedback.
   - Anti-manipulation safeguard active.

5. **Wealth & Capital Engine**:
   - Asset allocation glide path (110 - age equity rule) & Bogleheads 3-fund portfolio.
   - Liquid emergency runway calculation & savings rate tracking.
   - Tax-efficiency waterfall hierarchy & licensed professional escalation flags.

6. **Learning Engine ("Learn Anything")**:
   - Active recall spaced repetition deck with SuperMemo SM-2 interval calculations.
   - Interactive Skill Decomposition Tree tracking legitimate practice hours and mastery checkpoints.

7. **Agent Factory**:
   - Meta-module to scaffold specialized sub-agents with strict inherited core guardrails.

8. **Weekly Retro & Self-Improvement**:
   - Automatic recommendation vs. outcome auditing.
   - 1-click review and approval for system upgrade proposals.

9. **Data Sovereignty & Local Enclave**:
   - Local-first storage in browser enclave (`localStorage` / IndexedDB).
   - Revocable explicit connector grants (HealthKit, Screen Time, Calendar, Bank Feeds).
   - 1-click encrypted JSON backup export & instant wipe.

## 🛠 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## ⚡ Deploy to Vercel

### Option 1: Vercel CLI (Fastest)

```bash
# Run Vercel deployment
npx vercel
```

To deploy directly to production:
```bash
npx vercel --prod
```

### Option 2: Git Repository

1. Push this directory to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial APEX operating system build"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/apex-agent.git
   git push -u origin main
   ```
2. Import the repository in your [Vercel Dashboard](https://vercel.com/new). Next.js is automatically detected with zero configuration required.
